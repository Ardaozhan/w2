# Decisions

## Publication license

W2 uses the MIT License for the competition source package. The copyright line uses the existing Git author name, Arda Özhan. `package.json` retains `private: true`; W2 is not configured for npm publication.

The public repository is https://github.com/Ardaozhan/w2. The published stable release is v0.1.0. The v0.2.0 release is intentionally pending a live trusted Codex TUI verification after the new hook definitions are relaunched. Competition-specific eligibility and submission requirements remain unverified until a target competition is selected.
