# Limitations

- The demo is local and read-only; there is no hosted service or multi-user collaboration.
- The workspace boundary is a credible local control layer, not a hardened container or OS sandbox.
- The benchmark is one run per condition per fixture and records Codex timeouts; it does not support a positive speed, safety, or reliability claim.
- Token and cost metrics are omitted where the local stream does not expose reliable values.
- Competition-platform submission and video recording remain human-operated steps.
