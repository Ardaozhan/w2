# W2 Scope

## Included

- A Codex CLI execution path for coding-agent tasks.
- Task contracts with acceptance criteria and explicit verifier references.
- Context manifests, recognized event records, Git diffs, and declared verification results.
- Human- and machine-readable Run Receipts.
- Deterministic `PASS`, `FAIL`, `UNPROVEN`, `ABORTED`, and `ERROR` outcomes.
- Local persistence, reproducible evidence, and a static judge demo.

## Not included

- Multi-agent orchestration or a general agent platform.
- An OS/container security boundary or universal native-tool broker.
- Exact Codex file-read tracing.
- Cloud execution, a hosted multi-user service, or team authorization.
- Enterprise billing, a plugin marketplace, a mobile app, or an IDE replacement.
- A runtime GPT-5.6 evidence mapper.
- A claim that W2 makes agents more correct or faster than raw Codex.
