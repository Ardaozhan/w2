# W2 Scope

## In scope for v1

- One clear coding-agent execution path.
- Structured context manifest, action/tool trace, code diff, verification, and
  acceptance evidence.
- Human- and machine-readable Run Receipts.
- Explicit `PASS`, `FAIL`, `UNPROVEN`, `ABORTED`, and `ERROR` outcomes.
- Deterministic facts separated from bounded AI interpretation.
- Local, reproducible development and verification.

## Out of scope for v1

- Multi-agent orchestration.
- Vector databases, broad RAG, or speculative memory systems.
- Enterprise RBAC, team collaboration, billing, or cloud fleet execution.
- Plugin marketplace, mobile app, IDE replacement, or CI/CD replacement.
- Autonomous project planning.
- Multiple coding-agent providers unless a later phase proves the need.

## Deferred work

The run engine, evidence persistence, execution safety/durability, benchmark
evidence, product UX demo, and judge-ready packaging are reserved for Phases
01–06. They remain locked after Phase 00.
