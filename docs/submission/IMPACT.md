# Impact

AI coding agents make software changes increasingly autonomously. Developers still need evidence that the requested work was completed and that the checks support the result.

W2 separates an agent's completion claim from deterministic evidence. Its Run Receipt brings the task, W2-supplied context, recognized activity, Git diff, verification results, and criterion-level evidence together. If a requirement lacks suitable evidence, W2 reports `UNPROVEN`.

This project makes no market-size estimate and claims no measured correctness, speed, or reliability improvement. Its potential impact is a clearer, more auditable handoff between coding agents and the people reviewing their changes.
