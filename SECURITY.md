# Security

W2 is not an OS or container security boundary. Codex's own sandbox controls Codex-native operations; W2 observes only structured activity delivered through supported Codex hooks, Git-visible changes, and verifier results.

Please report vulnerabilities through GitHub's private vulnerability reporting or a GitHub Security Advisory for this repository. Avoid filing exploitable details in a public issue. If private reporting is unavailable, open a minimal issue asking maintainers to enable or provide a private reporting route without including sensitive details.
